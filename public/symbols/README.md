# Apple SF Symbols для бота «Вчасно»

Комплект оригинальных монохромных иконок Apple SF Symbols для кнопок, меню и создания премиум-эмодзи в Telegram.

## Структура папок в архиве
- **`PNG_Black_512x512/`** — монохромные темные иконки с прозрачным фоном (512×512 px)
- **`PNG_White_512x512/`** — монохромные светлые иконки с прозрачным фоном (512×512 px, идеально для темной темы и Telegram Custom Emoji)
- **`SVG_Vector/`** — оригинальные векторные файлы в формате SVG
