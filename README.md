# Вчасно — Telegram Mini App (График зарядок)

Премиальное iOS-приложение (Telegram Mini App) для бота **«Вчасно»**, разработанное на React 18, TypeScript, Tailwind CSS и оригинальных векторных иконках **Apple SF Symbols**.

## ✨ Особенности

- **Дизайн в стиле iOS:** Стеклянные эффекты (Glassmorphism), мягкие тени, скруглённые карточки, виброотклик (Telegram Haptic Feedback).
- **Адаптивная тема:** Автоматическое определение тёмной и светлой темы пользователя (синхронизация с темой Telegram и системными настройками).
- **Полноэкранный режим:** Автоматическое открытие на весь экран (`expand()`, `requestFullscreen()`), поддержка `safe-area-inset` для чёлки и Dynamic Island.
- **Интерактивный календарный график:**
  - Горизонтальный скроллер дней недели с числами и цветовыми индикаторами выполнения.
  - Умный чек-лист устройств на каждый день (Пн–Вс).
  - Воскресный аудит незаряженных устройств («долги» за неделю).
  - Кнопка «Зарядить всё на сегодня».
- **Синхронизация с Google Apps Script:**
  - Оптимистичный UI с мгновенным сохранением в кэш.
  - Фоновый обмен данными с Web App скриптом бота.
  - Автономный режим при отсутствии интернета.

## 📦 Деплой на Vercel через GitHub

1. **Создайте репозиторий на GitHub** (например, `vchasno-miniapp`) и отправьте код:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Vchasno Telegram Mini App"
   git branch -M main
   git remote add origin https://github.com/<ваш-username>/vchasno-miniapp.git
   git push -u origin main
   ```

2. **Подключите в Vercel:**
   - Перейдите на [vercel.com](https://vercel.com) и нажмите **Add New Project**.
   - Выберите ваш репозиторий `vchasno-miniapp`.
   - Нажмите **Deploy** (настройки определятся автоматически: Vite, Output: `dist`).
   - (Опционально) Добавьте переменную окружения `VITE_GAS_API_URL` со ссылкой на опубликованный Google Apps Script Web App.

## 🤖 Подключение к боту в Telegram (@BotFather)

1. Откройте `@BotFather` в Telegram.
2. Введите `/newapp` или `/myapps` $\rightarrow$ выберите вашего бота.
3. Укажите название приложения (например, `Вчасно` или `График зарядок`).
4. Введите короткое описание.
5. Укажите ссылку на ваше приложение на Vercel (например: `https://vchasno-miniapp.vercel.app`).
6. Загрузите иконку (640x360 px для превью).
7. Готово! Теперь бот может отправлять кнопку Mini App или открывать её по команде.
